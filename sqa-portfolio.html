Process

My testing process

The same clear steps on every project.

  1. 01

    Understand the app

    Learn the features, flows and requirements.

  2. 02

    Write test cases

    Positive, negative and edge cases for each module.

  3. 03

    Execute

    Run each test case and mark it pass or fail.

  4. 04

    Report bugs

    Clear steps, expected result, severity and priority.

  5. 05

    Retest

    Verify fixes and check nearby features again.

  6. 06

    Share the final report

    Test case and bug sheet with the final status.

For web projects

  • Test on Chrome and at least one more browser.
  • Check both mobile and desktop views.
  • Note any Console errors with the bug report.
